========================================================
covers 目录 —— 首页轮播海报的图片放这里
========================================================

【怎么用】

1. 把图片放进这个目录（public/covers/）。
2. 命名必须是 cover-1.jpg、cover-2.jpg、cover-3.jpg …… 从 1 开始、
   连续、不跳号。断号就停（例如只有 1、2、4，程序只读到 2）。
3. 支持的扩展名：jpg / jpeg / png / webp，第 1 张用哪个都行。
4. 上传后 Cloudflare 会自动重新部署，首页会随机挑几张用作轮播海报。

【自带的 6 张是什么】

cover-1.png ~ cover-6.png 是程序生成的极简风景海报
（满月 / 落日海面 / 极光 / 城市天际线 / 星夜 / 沙丘落日）。
只是为了让首页开箱就有画面，你可以随时替换或删除。

删除后卡片会自动改用「CSS 画的天空 + 日月 + 地平线」兜底，
界面依然完整，不会出现破图或空白。

【想自己再生成几张？】

同目录的 生成封面.py 就是生成脚本（纯 Python 标准库，无需安装任何东西）：

  cd public/covers
  python3 生成封面.py                 # 覆盖生成 6 张 720x960
  COVER_W=900 COVER_H=1200 python3 生成封面.py    # 换尺寸

想调颜色/构图，直接改脚本里的 COVERS 列表：每一项就是一张图的配方
（天空渐变色、日/月的位置与大小、山脊起伏、城市天际线……）。

【想用任意文件名？】

在本目录新建 manifest.json（内容如下），程序会优先读它，不再按 cover-N 找：

  ["我的海报A.jpg", "我的海报B.png", "https://example.com/x.jpg"]

两种方式别混用：manifest.json 一旦存在，cover-N 的自动探测就完全失效。

【尺寸建议】

竖版 3:4 最好（720x960、900x1200 都行，自带的就是 720x960）。
程序会自动裁切填满，比例不同也不会拉伸变形，只是边缘会被裁掉一点。
建议单张控制在 500KB 以内，车机加载更快。自带的 6 张共约 1.2MB。

【首页显示哪几张】

每张海报是"随机"分配给各个影视源的，每次刷新页面重新随机一次
（不是每次切页面都变，避免视觉跳动）。
图片不够分时循环复用，所以同一张可能被两个源同时用到。
